AI Interview Preparation Platform
Overview

The AI Interview Preparation Platform is a full-stack application designed to help students prepare for technical interviews. The system allows users to answer interview questions and receive an evaluation score generated by a machine learning model.

The project demonstrates the integration of:

Machine Learning

Backend APIs

Frontend UI

Containerization

Kubernetes deployment

This project is being built as a placement-ready portfolio project showcasing skills in ML, full-stack development, and DevOps.

Step-by-Step Setup Guide
1. Clone or Create Project Folder
mkdir ai-interview-platform
cd ai-interview-platform
Backend Setup

Navigate to backend folder

cd backend
Create Virtual Environment
python -m venv venv

Activate environment (Windows)

venv\Scripts\activate
Install Python Dependencies
pip install fastapi
pip install uvicorn
pip install pandas
pip install scikit-learn
pip install joblib

Or install all dependencies using:

pip install -r requirements.txt
Machine Learning Model Setup

Navigate to ML model directory:

cd ml-model
Train Model

Run the training script:

python train_model.py

This will:

Load dataset

Train ML model

Save model file

Output generated:

model/answer_model.pkl
Frontend Setup

Navigate to frontend folder:

cd frontend
Create React App
npx create-react-app react-app

Move into the React directory:

cd react-app
Install Dependencies

Axios is used to connect React to backend API.

npm install axios
Run Frontend

Start React development server:

npm start

Default URL:

http://localhost:3000
Fix React Error (reportWebVitals)

If the following error appears:

Module not found: Can't resolve './reportWebVitals'

Open:

src/index.js

Remove:

import reportWebVitals from './reportWebVitals';

And remove:

reportWebVitals();
Current Application Workflow

User opens web application.

A sample interview question is displayed.

User types their answer.

Clicking Evaluate Answer sends request to backend.

Backend passes answer to ML model.

Model generates score.

Score displayed on UI.

Running the Full Project

Run Backend:

uvicorn main:app --reload

Run Frontend:

npm start
